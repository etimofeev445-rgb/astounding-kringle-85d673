# UAT Market — Telegram Mini App

UAT Market — міні-застосунок для Telegram-бота з корисними інструментами для України:

- **Пошук** по всьому застосунку (банки, МФО/ЄДРПОУ, документи, валюти, свята) + швидке відкриття `@каналу` чи бота в Telegram
- **Курс валют** — офіційний курс НБУ, готівковий курс ПриватБанку, курс monobank, конвертер
- **Банки України** — довідник з МФО, ЄДРПОУ, гарячими лініями й посиланнями (копіювання в один дотик)
- **ДП Документи** — шаблони (розписка, довіреність, заява, акт виконаних робіт, рахунок): заповнив поля → скопіював або надіслав у чат
- **Калькулятор** — звичайний, ПДВ, депозит (з податками 18% + 5%), кредит (ануїтет)
- **Календар** — державні свята та памʼятні дати України, включно з Великоднем і Трійцею, лічильник робочих днів

## Технології

TanStack Start (React 19, Vite 7), Tailwind CSS 4, Telegram WebApp SDK, Netlify (хостинг + серверні функції для отримання курсів).

## Локальний запуск

```bash
pnpm install
netlify dev
```

## Підключення до бота

1. Відкрийте [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот → **Bot Settings → Menu Button** (або `/newapp`).
2. Вкажіть URL сайту на Netlify, наприклад `https://astounding-kringle-85d673.netlify.app`.
3. Відкрийте бота — кнопка меню запустить UAT Market.

## Що можна додати далі

- Збереження заповнених документів та обраних валют для кожного користувача
- Сповіщення ботом про зміну курсу
- Курси інших банків і криптовалют
